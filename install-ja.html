深い夜

脳波サウンドに雨音や波の音を重ねて流し、決めた時間になると静かに止まります。

  • 脳波サウンド3種類
  • 自然の音5種類をミックス
  • オフタイマー
  • マイサウンド保存
  • 睡眠記録カレンダー
  • オフラインでも使える
  • 韓国語・日本語
お使いの端末です

Androidにインストール

インストールファイル（APK）をダウンロードして、そのままインストールします。1分で終わります。

!
LINE・Instagramなどのアプリ内で開いた画面ではダウンロードできないことがあります。右上の ⋮ メニューから ブラウザで開く（Chrome）を選んでください。
APKをダウンロード 約50KB
  1. 上のボタンでダウンロード

    「この種類のファイルはデバイスに悪影響を及ぼす可能性があります」という警告が出たら ダウンロード を押してください。ストア以外から入手するファイルなので表示される案内です。

  2. ダウンロードしたファイルを開く

    画面下の完了通知の 開く を押してください。通知を見逃したら ファイル → ダウンロード から 深い夜.apk を押します。

  3. 「提供元不明のアプリ」を許可

    最初の1回だけ表示されます。設定 を押して この提供元のアプリを許可 をオンにし、戻ってください。

  4. インストールを押す

    Playプロテクトが「確認されていないアプリ」と表示したら 詳細 → インストールする を押してください。個人が作ったアプリなので表示される案内です。

  5. 開く

    インストールが終わると、アプリ一覧に月のアイコン 深い夜 が表示されます。

お使いの端末です

iPhoneにインストール

Safariでアプリのページを開き、ホーム画面に追加 するとアプリのように使えます。App Storeは必要ありません。

!
今はLINE・Instagramなどのアプリ内で開いているため、ホーム画面に追加 ができません。Safari で開いてください。
Safariで開く
コピーしたリンクをSafariのアドレスバーに貼り付けるか、画面下の ⋯・共有 メニューから Safariで開く を選んでください。
Safariでアプリのページを開く
  1. 上のボタンでアプリのページを開く

    必ず Safari で開いてください。深い夜の画面が出たら次へ進みます。

  2. 共有ボタンを押す

    画面下（またはアドレスバーの横）の 共有 を押してください。共有ボタンが見えないときは、先に ⋯ ボタンを押すと出てきます。

  3. 「ホーム画面に追加」を選ぶ

    メニューを下にスクロールすると ⊕ ホーム画面に追加 があります。見つからないときは さらに表示 を押して探してください。

  4. 「Webアプリとして開く」をオンにして追加

    名前はそのままにして、Webアプリとして開く のスイッチがあればオンのまま、右上の 追加 を押してください。

  5. ホーム画面から起動

    月のアイコンが表示されます。押すとアドレスバーなしでアプリのように開き、一度開けばインターネットがなくても使えます。画面は自動で日本語になります。

スマホでこのページを開く
カメラでQRコードを読み取ると、スマホからすぐインストールできます。

寝るときに画面を消してもいいですか？

Android：画面を消しても音は流れ続けます。再生中は通知欄に再生中と表示されます。

iPhone：画面を消すと音が止まることがあります。明るさを下げて、画面をつけたまま伏せて置いてください。

アップデートはどうすればいいですか？

Android：このページからAPKをもう一度ダウンロードしてインストールすると、上書きされます。睡眠記録はそのまま残ります。

iPhone：特に何もしなくて大丈夫です。アプリを開くと新しいバージョンを受け取り、完全に閉じて開き直すと切り替わります。

言語を切り替えるには？

アプリ右上の 한국어 / 日本語 ボタンを押すとすぐ切り替わります。最初はスマホの言語設定に合わせて開きます。

アプリを削除するには？

ほかのアプリと同じです。ホーム画面でアイコンを長押しして 削除（iPhone）または アンインストール（Android）を押してください。
